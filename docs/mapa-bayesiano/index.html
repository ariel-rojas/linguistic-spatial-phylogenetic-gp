Mapa bayesiano global

Este mapa muestra la ejecución bayesiana completa: observaciones, lenguas usadas para entrenar, test reservado e imputaciones propuestas. Elegí capas desde el control arriba a la derecha y pulsa un punto para ver sus probabilidades e intervalos. Las fichas de test e imputación permiten abrir histogramas posteriores por lengua.

El test contiene 276 lenguas (239 aciertos y 37 errores); hay 940 propuestas de imputación. Son predicciones para revisar, no nuevas observaciones. La primera carga puede tardar porque el mapa conserva todas sus capas.
